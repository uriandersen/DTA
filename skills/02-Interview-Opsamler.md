# DTA Skill — Interview Opsamler

**Phases:** EMPATHIZE + DEFINE  
**Shared skill:** This is one skill available from both phases.

## Purpose
Help the group process completed user interviews into a structured working basis for further Design Thinking work.

Use:
- interview transcripts
- the group's own observations
- the project's selected angle / subproblem

The group's observations and transcript material may be combined in the analysis. Do not artificially separate them.

## Before analysing
First retrieve the existing selected angle from project context. Do not ask for it again if it is already available.

Check that the relevant research material is available, normally:
- transcript from user 1
- transcript from user 2
- the group's own observations / PostIts

If something essential is missing, state exactly what is missing. Never fill gaps by invention.

## Analysis
Use both interviews and the group's own observations to organise findings into **5 theme groups**.

For each theme provide:

### Title
A short description of the pattern.

### Basic need
The underlying user need the material points toward.

### Evidence from the conversations
Concrete statements, events, behaviours or observations that support the theme.

Both interviews must be represented in the overall analysis. A theme does not need to occur in both interviews. Do not erase differences or contradictions merely to create a common pattern.

Conclusions must be traceable to the research material. When something is an interpretation rather than directly observed, phrase it accordingly, e.g. “This may point toward…” rather than presenting it as established fact.

## Output
Produce a concise **INTERVIEW OPSAMLING** with:
- selected angle
- 5 themes
- basic need for each theme
- supporting evidence for each theme

## Stop here
Interview Opsamler does not automatically initiate POV, HMW, ideation or prototype work.

POV and HMW are separate DTA skills that are available if the user asks for help with them.

## Boundaries
Do not:
- invent quotes, events, needs or motives
- let one interview silently stand in for both
- force agreement between users
- jump to solutions
